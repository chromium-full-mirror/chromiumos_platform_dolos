# Get Dolos Versions Script

This script is a utility to actively check the current firmware version of Dolos devices attached to a fleet of labstations. It reads a list of devices from a CSV file, connects to each labstation via SSH, and runs `doloscmd` to query the firmware version.

It's designed to be used as a monitoring tool during a phased rollout to verify that firmware updates have been successfully applied.

## Prerequisites

- gcert
- SSH access to labstations in the fleet.
- The `doloscmd` tool must be available on the labstations being accessed.

## How to Use

**Note:** All commands should be run from the `tools/dolos_fleet_rollout` directory.

Run the script from the command line, providing an input CSV of devices, a path for the output report, and the expected firmware version you want to check for.

```bash
./get_dolos_versions.py \
    --input-csv all_dolos_devices.csv \
    --output-csv version_report.csv \
    --set-version <firmware_version>
```

## Arguments

*   `--input-csv` (required): The path to the input CSV file containing device information. The file must contain `labstation` and `uartname` columns. The CSVs generated by `get_dolos_devices.py` are compatible.
*   `--output-csv` (required): The path where the output CSV report will be saved.
*   `--set-version` (required): The target firmware version string to compare against.

## Output

### Console Output

The script will print its progress to the console, indicating which host it is checking. Upon completion, it will display a summary like this:

```
--- Version Rollout Summary ---
Expected version: 0.214.0-c792f03
Total devices checked: 150
Devices with expected version: 145
Devices with different version: 2
Devices where version check failed: 3
Rollout progress: 96.67%
```

### Output CSV File

The script generates a new CSV file at the path specified by `--output-csv`. This file will **only contain the devices for which the reported firmware version did not match the expected version**.

The format of this output CSV is identical to the input CSV file. This allows you to use it directly as input for the `dolos_fleet_rollout.py` script to retry the update on the failed devices.

If all devices have the correct version, no output file will be created.
