# Dolos Fleet Rollout Script

This script is used to manage the rollout of new Dolos firmware to a fleet of devices. It takes a CSV file containing a list of DUT hostnames and allows you to set the firmware version and schedule repairs.

For monitoring the progress of the rollout, see `get_dolos_versions.md`.

## Prerequisites

- gcert
- The `shivas` command-line tool installed and logged in.

## How to Use

**Note:** All commands should be run from the `tools/dolos_fleet_rollout` directory.

First, generate a CSV file of Dolos devices using the `get_dolos_devices.py` script. Then, you can use this script to manage the rollout.

### Set Firmware Version and Schedule a Repair

To set a new firmware version for all devices in your CSV and schedule a repair task to apply the update, run:

```bash
./dolos_fleet_rollout.py --csv-file <path_to_your_csv_file>.csv --set-version <firmware_version> --repair
```

### Schedule a Repair Only

To schedule a repair for all devices in a CSV without changing their target firmware version, run:

```bash
./dolos_fleet_rollout.py --csv-file <path_to_your_csv_file>.csv --repair-only
```

This is useful for retrying updates on devices that failed, using a list of mismatched devices generated by the `get_dolos_versions.py` script.

### Scan Firmware Versions

To check the current firmware version of all devices in a CSV file without making any changes, run:

```bash
./dolos_fleet_rollout.py --csv-file <path_to_your_csv_file>.csv --ufs-scan
```

The script will print the version for each device and a summary of all versions found.

## Arguments

*   `--csv-file` (required): Path to the CSV file with the list of devices. The CSV should have a header row and the hostnames should be in the first column.
*   `--set-version`: The target Dolos firmware version to set for all devices.
*   `--repair`: A flag to schedule a repair task for all devices in the CSV. Can be used with `--set-version`.
*   `--repair-only`: A flag to only schedule a repair task. If this is used, `--set-version` will be ignored.
*   `--ufs-scan`: A flag to scan and report the current firmware version of all devices in the CSV. No changes will be made to the devices.
